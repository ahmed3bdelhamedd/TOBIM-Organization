# TOBIM — Administrative & Payment Management System

A professional full-stack enterprise dashboard built for **TOBIM** to manage engineering courses, student subscriptions, payments, outstanding dues, and requests tracking.

## 🚀 Tech Stack
- **Backend:** C# / .NET Core, Entity Framework Core
- **Database:** SQLite
- **Frontend & UI:** Tailwind CSS, Alpine.js (Interactive UI with smooth animations)

## ✨ Features
1. **New Subscription (`اشتراك جديد`):** Easy-to-use form to register new students, select departments (Architectural, Structural, Courses), select rounds, and upload payment proofs.
2. **My Subscriptions (`اشتراكاتي`):** Real-time tracking and filtering of subscriptions with statuses (`Rest`, `Full Pay`, `Hold`, `Return`).
3. **All Subscribers (`كل المشتركين`):** Centralized database view with Sales tracking.
4. **Due Payments (`المستحق`):** Monitor pending and remaining payments instantly.
5. **My Requests (`طلباتي`):** Track operational requests like ID generation and course access unlocking.
